Store-Analytics.
Ülesanne koosneb kahest osast:
1) Konsoolirakendus, mis:
laeb poe tooted,
rakendab allahindluse reegleid,
arvutab statistikat,
väljastab aruande konsooli.
2) Veebirakendus, mis:
kuvab toodete nimekirja,
võimaldab lisada uusi tooteid,
arvutab laoseisu staatuse,
võimaldab filtreerida või sorteerida,
salvestab andmed LocalStorage’i,
taastab andmed pärast lehe värskendamist.
Kirjutatud dünaamiliselt.

Kuidas käivitada:
npx tsc - teeb kompileerimist kogu projekti
node dist/data/main.js - käivitab konsoolirakendust
Veebirakenduse link: https://iljasizonenko.github.io/Store-Analytics/
